# Namma-Nala

## Project Overview
Namma-Nala is an Android application developed using GenAI tools to help citizens report infrastructure issues such as damaged roads, garbage accumulation, water leakage, and public maintenance problems.

## Features
- User Login
- Upload infrastructure issue images
- Complaint submission
- Category selection
- Easy interface for citizens

## Tech Stack
- Kotlin
- Jetpack Compose
- Android Studio
- Firebase (if used)

## Installation
1. Clone repository
2. Open in Android Studio
3. Run project
